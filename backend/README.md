# Tuleva backend

Tähän kansioon toteutetaan myöhemmin NestJS + TypeScript -backend.
Tietokannaksi on suunniteltu PostgreSQL. Varsinaisten äänitiedostojen
tallennusratkaisu päätetään myöhemmin.

Backend-sovellusta, riippuvuuksia tai tietokantayhteyttä ei ole vielä alustettu.
Musiikin toisto ja reaaliaikainen äänenkäsittely toteutetaan selaimessa.
